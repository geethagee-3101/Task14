# Task 14: Basic Sales Summary

## Objective
Calculate total sales, average sales, and transaction count using Microsoft Excel.

## Tools Used
- Microsoft Excel

## Dataset
A sample retail sales dataset containing 50 transactions with:
- Transaction ID
- Date
- Product
- Category
- Region
- Quantity
- Unit Price
- Sales

## Excel Functions Used
- `SUM()` – Calculates total sales.
- `AVERAGE()` – Calculates average sales.
- `COUNT()` – Counts the number of transactions.

## Key Performance Indicators (KPIs)

| KPI | Result |
|---|---:|
| Total Sales | ₹11,88,905.64 |
| Average Sales | ₹23,778.11 |
| Transaction Count | 50 |

## Workbook Structure
1. **Transactions:** Contains the sales dataset.
2. **Summary:** Displays the three KPIs with Excel formulas.

## Key Learnings
- Understanding basic sales analysis.
- Using Excel formulas.
- Calculating business KPIs.
- Creating a simple sales summary.
